Thematische Cluster: Universitäten × ÖFOS-Bereiche

Jeder Knoten = eine Professur. Farbe = Universität. Position = ÖFOS-Bereich (1–6). Größe = h-Index. Knoten, die nahe beieinander liegen, gehören zum selben ÖFOS-Bereich — Überlappungen zwischen Universitäten sind dort sichtbar, wo Knoten verschiedener Unis im selben Bereich auftauchen.
